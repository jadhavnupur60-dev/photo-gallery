# Responsive Photo Gallery

A responsive photo gallery web page built using **HTML5**, **CSS Grid**, and **Flexbox**.

## Features
- **Flexbox Header:** Clean navigation bar aligned seamlessly across devices.
- **CSS Grid Layout:** Multi-column layout that automatically displays image cards.
- **Responsive Design:** Uses media queries to switch from 3 columns on desktop to 2 columns on tablets, and 1 column on mobile screens.
- **Dynamic Image Loading:** Uses placeholder images served via Lorem Picsum API.
